## ویژگی‌های سیستم

### بخش عمومی
- نمایش لیست مطالب
- صفحه جزئیات هر مطلب
- طراحی واکنش‌گرا

### بخش مدیریت
- صفحه ورود امن
- مدیریت نشست (Session)
- عملیات کامل CRUD (ایجاد، مشاهده، ویرایش، حذف)
- ایجاد، ویرایش و حذف مطالب

## راه‌اندازی پروژه

### پیش‌نیازها
- Visual Studio 2022
- SQL Server 
- .NET 8.0 SDK

### مرحله ۱: ایجاد دیتابیس
1. فایل SQLQuery.sql را در SQL Server اجرا کنید
2. دیتابیس SimpleCMS ایجاد خواهد شد

### مرحله ۲: اجرای پروژه
1. فایل SimpleCMS.sln را در ویژوال استودیو باز کنید
2. کلید F5 را بزنید
3. پروژه در مرورگر اجرا می‌شود
